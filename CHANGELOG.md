# Changelog

## 0.2.0 (proposed)

Changes since [`v0.1.0`](https://github.com/soulsteads/soulsteads-model-router/releases/tag/v0.1.0).

### Highlights

- Add offline policy inspection and routing plans, explicit session continuation placement, and bounded tool compatibility on managed Responses routes.
- Update routing audit and status output, setup and client compatibility guidance, and offline and HTTP validation.
- Document how to check restart and lost session-pin behavior before migrating client traffic.
- Standardize `LICENSE` and `NOTICE` with author Scott Glover and `Copyright (c) 2026 Soulsteads`. The Apache-2.0 terms are unchanged.
